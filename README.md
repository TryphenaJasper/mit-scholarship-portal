Scholarwise:
A Java-based web application designed to help students explore scholarships, analyze eligibility gaps, and identify possible ways to improve their scholarship eligibility.

About the Project:
The MIT Scholarship Portal is an informational and decision-support platform that helps students understand scholarship opportunities based on their academic and personal profiles. It provides scholarship information, identifies unmet eligibility requirements, and presents possible priorities for addressing those gaps.

Key Features:

1. Applicable Scholarships
- Displays scholarships relevant to the student's profile.
- Helps students explore scholarship opportunities based on eligibility criteria.
- Provides an overview of scholarship requirements.

2. Gap Analysis
- Compares student information with scholarship eligibility requirements.
- Identifies unmet criteria and eligibility gaps.
- Provides clear information about the requirements that need attention.
- Helps students understand why they may not meet particular scholarship criteria.

3. Priority Resolution
- Organizes identified eligibility gaps by priority.
- Helps students understand which gaps may be addressed first.
- Supports informed planning by highlighting important requirements and potential improvement areas.

Tech Stack:
- Frontend: React, HTML, CSS, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Build Tool: Apache Maven
- Communication: REST APIs
  
Work Flow:
1. Student information and scholarship requirements are retrieved from the database.
2. The portal identifies scholarships relevant to the student's profile.
3. Gap Analysis compares the student's details against applicable requirements.
4. Priority Resolution organizes the identified gaps to help students plan their next steps.

Project Objective:
To make scholarship information easier to understand and help students make informed decisions through personalized scholarship discovery, eligibility gap identification, and priority-based resolution.
